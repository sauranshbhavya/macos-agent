# SONNY-451 — [s] at the start of a command routes it to screen use through the resolver, with the
# app read from the command's words and checked against what is installed or asked for; and an
# open_app, open_workspace or open_url step, and a screen-control session, bring the app the user
# was in back in front when they are done. Property: the prefix is the first and only new door,
# exact and case-insensitive, and every gate a planned session meets stands in front of it; no app
# named is a clarification and its answer completes the command; an open that moved the front
# restores it, on a throw too, and one that moved nothing restores nothing; only a switch is a
# restore, and an app that has quit is never asked to come back; a session restores the user's app
# through the same restorer on every exit and at a pause, never over the app under control while
# Sonny acts; and a delegated [s] cannot start a second session. After PR #238's review: a prefixed
# command at an app that is not running opens it first; every answer to the door's question stays on
# the prefixed route; an alias alone asks what to do; two apps in one sentence ask which; an open
# whose app the next session controls hands the user's app to that session; a session gives the
# user's app back when it ends by Stop or by an error; a restore is live only at the noted bundle; the
# shipping composition reads the running instances once; and the prefixed Safe-mode and advisory
# tests drive the gates they are named for.
#
# X13 to X23 are PR #238's findings, each applied by hand on this branch and killed by the tests
# named for it; X3's killer changed in that round, because an answer is no longer appended, and it
# was re-applied by hand and killed. X24 to X26 are its delta review's: the chain gives back what its
# focus carry still holds when a session after an open never starts, an answer's leading preposition
