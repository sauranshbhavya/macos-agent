# SONNY-451 — [s] at the start of a command routes it to screen use through the resolver, with the
# app read from the command's words and checked against what is installed or asked for; and an
# open_app, open_workspace or open_url step, and a screen-control session, bring the app the user
# was in back in front when they are done. Property: the prefix is the first and only new door,
# exact and case-insensitive, and every gate a planned session meets stands in front of it; no app
# named is a clarification and its answer completes the command; an open that moved the front
# restores it, on a throw too, and one that moved nothing restores nothing; only a switch is a
# restore, and an app that has quit is never asked to come back; a session restores the user's app
# through the same restorer on every exit and at a pause, never over the app under control while
# Sonny acts; and a delegated [s] cannot start a second session.
#
# X4 and X5 were rewritten on SONNY-451's rebase over SONNY-440: their `from` blocks named code the
# break fix changed (`onRestore(before)` became `onRestore(before.app)`, and the session stopped
# restoring through the synthesizer), so they matched nothing and a battery would have refused them
# at pre-flight. X7 to X12 are the founders' decision of 2026-09-12 and the defects that decision's
# rebase found.
#
# Killers expected (hand-traced, and X4, X5, X7, X8, X9 and X10 hand-applied on this branch; the
# founders' weekly battery measures): X1 by every ScreenUsePrefixTests plan test and every
# VisionSessionRunTests aPrefixedCommandMeets… test; X2 by ScreenUsePrefixTests

# (anAppOpenBringsThePreviousAppBack); X7 by FocusRestorerTests (aLaunchIsNotReportedAsARestore,
