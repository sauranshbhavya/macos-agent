# SONNY-506 and SONNY-508 — the two content rules that decide whether Sonny can be pointed at a site
# and left alone. Swift half only; no file under server/ changes on this branch.
#
# Every mutant below weakens a rule in the direction that matters — it lets through something the
# branch claims is refused — except M8 and M9, which widen one and are here because "0 false refusals
# over the 473 shipped packs" is as load-bearing a claim as the refusals: a rule that refuses real
# packs is one a lane switches off.
#
# What is deliberately NOT here, so a reader does not take its absence for an oversight: a mutant
# that adds a word to `SkillPackCredentialRule.privacyObjects`. Adjacency is what makes that list
# safe — a widened word only excuses `secret` when it lands immediately beside it — so a widening
# mutant is not killable by any step a pack would plausibly write, and a mutant nobody can kill is a
# finding with no answer rather than a measurement. The list's contents are a value judgement held by
# `aControlNamedSecretLoadsAndACredentialNamedSecretStillDoesNot`'s two tables instead.
