# SONNY-506 and SONNY-508 — the two content rules that decide whether Sonny can be pointed at a site
# and left alone. Swift half only; no file under server/ changes on this branch.
#
# Every mutant below weakens a rule in the direction that matters — it lets through something the
# branch claims is refused — except M8 and M9, which widen one and are here because "0 false refusals
# over the 473 shipped packs" is as load-bearing a claim as the refusals: a rule that refuses real
# packs is one a lane switches off.
#
# An earlier draft of this file said a `privacyObjects`-widening mutant was not worth writing because
# adjacency made one unkillable. That was false and review-268's F3 disproved it by running one:
# adding `client` puts the widened word exactly where the credential sense already puts it, so
# "Paste the client secret." is excused and the held row fails. It is M11 now. The wrong reasoning
# came from trying two words (`field`, `page`) that were not adjacent in any row and generalising
# from two misses — which is this repository's own rule about a control that has not been shown to
# fire, applied to a mutant.
