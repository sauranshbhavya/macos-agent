# catalogue row has exactly one pack. Swift half only.

# W1 to W6 undo the word-list change one word, or one read, at a time. Each is killed by the held
# samples in SkillPackTests.theTriggerCheckRefusesOrdinaryLanguageAndAllowsTheSitesOwnWords
# (Tests/MacAgentCoreTests/SkillPackTests.swift). No shipped pack uses any of these words alone as a
# trigger, so everyShippedTriggerIsDistinctiveOrAnchoredToItsSite is not expected among the killers.
#
# C1 is the completeness test's mutant. It is not "the completeness test's assertion removed": a
# mutant of a test's own assertion survives on every tree where the property holds, which is every
# tree a battery runs on, so it would be a survivor every week and measure nothing. C1 instead
# removes one pack from what the tests read, the way a lost file would, and the other validating
# test cannot see it: its file count and pack count drop together. The expected killer is
# SkillPackTests.everyCatalogueRowHasExactlyOnePack, naming zoominfo. The assertion itself was shown
# to fail with one pack file removed, by hand, on the branch (its changelog entry has the run).
