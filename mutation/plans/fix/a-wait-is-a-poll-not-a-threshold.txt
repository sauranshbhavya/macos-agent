# SONNY-515 — a wait on the stub transport is judged by a canary through the same kind of pipeline,
# not by the clock alone, and every stub request's handler runs on a thread of its own. SONNY-418 — the
# routine fixtures build their 9am in the machine's own zone, the zone the scheduler reads.
#
# SWIFT HALF. Every path below is under Tests/, so scripts/mutate-all runs this plan against the
# flagged Swift suite. These mutants target test-support and fixture code on purpose: the property
# this branch protects is the honesty of the test harness itself, and the killers are the tests
# written for that harness.
#
# Not run on this branch (founder-triggered batteries, 2026-09-10). The killers named are the tests
# each mutant was written against, not a measurement.
#
# Intended killers:
#   M1 — CanaryBackstopTests.aStuckOutcomeRecordsASecondIssueAndEndsTheTest (three issues become two,
#        and the second is no longer the stuck sentence). The kickoff's own mutant: without the second
#        issue a stuck wait records only declared wordings and a battery reads a real kill as
#        UNATTRIBUTED — CLAUDE.md's SONNY-259 rule.
#   M2 — aFalseConditionBesideACanaryThatGetsNoAnswerIsStarvedAtTheCeiling,
#        stuckOutranksBrokenAndBrokenOutranksStarved and theBlockingFormReachesTheSameFourVerdicts: a
#        starved wait reported stuck, so a busy machine records the evidence sentence — the
#        manufactured kill this branch exists to end.
#   M3 — every abandonUnlessHeld test that records issues (stuck, broken, starved): the abandonment
#        turned back into a return, so the line after the wait runs (PR #153's F2 shape).
#   M4 — noCanaryIsSentBeforeTheDeadline and everyCanaryTripBeginsAfterTheDeadline: the canary
#        started with the wait rather than at its deadline, so trips completed before a stall could
#        vouch for a pipeline that was frozen when the verdict was taken.
#   M5 — BackendStubURLProtocolTests.eightyHeldHandlersAllStartWhileEveryOneOfThemIsStillHeld: the
#        handler back on a concurrent dispatch queue, served from GCD's constrained pool, which
#        `sysctl kern.wq_max_constrained_threads` caps at 64 on the Mac this was written on. It dies
#        on HangBackstop's stuck verdict and the second issue that wait records, which takes that
#        backstop's thirty-second deadline and five hundred looks at the least — 100.7 s in the
#        review's full run of it (PR #277, F5). Killing it never depended on this test alone: in that
#        run about a hundred other backend tests failed on the client's own timeout.
#   M6 — aFalseConditionBesideACanaryThatComesBackFailedIsBrokenRatherThanStarved and
#        theBlockingFormReachesTheSameFourVerdicts: a canary trip that came back failed counted as one
#        that completed, which turns a broken canary's path into a stuck verdict about the code.
#   M7 — every ScheduledRoutineRunTests test that needs its routine to have run at tenAM, among them
#        aTrustedRoutineRunsUnattendedAndRecordsItsRunEverywhere and
#        aScheduledRunStoresWhatItProducedAndThePlanItRan.
#   M8 — aFalseConditionBesideACanaryThatGetsNoAnswerIsStarvedAtTheCeiling and the blocking form's
#        starved leg: a trip that got no answer counted as one that came back failed, which is PR
#        #277's F3 the other way round — silence reported as "not a busy machine".
#   M9 — stuckOutranksBrokenAndBrokenOutranksStarved, and the two broken-verdict waits, which then run
#        to their 120 s ceiling and come back starved instead of hanging: the broken verdict removed,
#        so a canary that keeps getting failures is called a busy machine again (PR #277's F3).
#
# **Why M7 pins a zone half a day from the machine's, and not America/New_York.** Pinning Eastern is
# exactly SONNY-418's defect, and on a Mac in Eastern it is invisible by construction: the fixture and
# the scheduler agree there, every test passes, and the mutant would come back SURVIVED on the very
# machines the founders run batteries on. That survivor would be true — it is the ticket's finding —
# but it would say nothing about whether the fixture still follows the scheduler. Twelve hours from
# the machine's own offset misses the three-hour catch-up window on every Mac, so the mutant tests the
# property rather than the founder's location.
