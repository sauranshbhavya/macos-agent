# SONNY-448 — Sonny quits while a sheet is up, and Relaunch Sonny ends the copy it replaces.
#
# The cause, measured with a standalone AppKit probe (the changelog entry has it): every sheet is a
# modal window whose preventsApplicationTerminationWhenModal defaults to true, and AppKit refuses
# termination silently, before the delegate is asked, while such a window is up. The fix clears the
# flag on every window when any sheet begins (SheetTerminationRelease), installed at launch; and,
# because SwiftUI takes a sheet down for termination by writing false to its binding, the first-run
# sheet's binding now records nothing (FirstRunCoordinator.withdrawUnanswered) instead of a skip.
#
# SWIFT HALF. Every path below is under Sources/.
#
# Not run on this branch (founder-triggered batteries, 2026-09-10). The killers below are the tests
# each mutant was written against, not a measurement.
#
# Intended killers:
#   Q1 — SheetTerminationReleaseTests.aSheetBeginningReleasesEveryWindowsHoldOnTermination and
#        .aSheetAppKitBeginsIsAttachedAlreadyReleased. This is the swallowed Quit put back: with the
#        hold left on, AppKit refuses ⌘Q, both menus' Quit, the Dock's Quit and the relauncher's
#        terminate under every sheet — the old copy survives a relaunch through exactly this.
#   Q2 — SheetTerminationReleaseTests.theAppInstallsTheReleaseAtLaunchBeforeAnySheetCanExist alone:
#        the type still works, and nothing in the shipping app ever turns it on.
#   Q3 — the same scan alone: installed, over no windows.
#   Q4 — the two behavioural tests in SheetTerminationReleaseTests that expect a release.
#   Q5 — the same two: at willBeginSheet the sheet is in no parent's `sheets` yet, so releasing only
#        the windows' current sheets releases nothing (measured in the probe, and the AppKit test
#        reads the same state).
#   Q6 — FirstRunSequenceTests.commandCenterPresentsTheSequenceAndBothDecliningControlsReachTheSameCall:
#        the skip put back on the first-run sheet's own binding, which is what a quit writes.
#   Q7 — FirstRunSequenceTests.quittingWithAStepOnScreenRecordsNothingAndTheNextLaunchLandsOnIt,
#        both arguments: a quit recorded as declining the step.
#   Q8 — the same test: the step left published after SwiftUI has taken the sheet down.
#   Q9 — ScreenAccessOnboardingTests.theShippingRelaunchersWiringIsOpenMinusNOnTheRunningBundle: the
#        relaunch that starts the new copy and never ends this one.
#   Q10 — FirstRunSequenceTests.quittingWithAStepOnScreenRecordsNothingAndTheNextLaunchLandsOnIt: a
#        quit that ends first run for good.
