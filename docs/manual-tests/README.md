# Historical manual-test records

The files here record checks from the former per-branch workflow. The older rows are in [the v1 checklist](../sonny-manual-test-checklist.md).

New branches do not need a file here, including a file that says no checks are owed. Put relevant macOS or product smoke checks in the PR or substantial Plane issue, then record the observed result. A packaged-app check matters when behavior depends on permissions, focus, Apple Events, Accessibility, screen capture, or real input. See the current [workflow](../../WORKFLOW.md).
