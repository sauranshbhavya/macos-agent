The pack stays shallow and the article that was read — `https://bubble.io/support/en/articles/10581123-creating-managing-projects`, title "Creating & Managing Projects | Bubble Support Center" — is recorded on the ticket so a later session does not pay for that reading twice. **Nothing in this repository would have refused it**: `app.bubble.io` is a subdomain of `bubble.io`, so the host check passes and is right to, and the URL's own text carries no credential word.
