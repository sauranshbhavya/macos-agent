**Three findings about the reader.**
- **A first read can come from the page before.** Right after navigating to `support.docusign.com`, a `find` answered by describing the RingCentral page the tab had just left. A read that waited for the new host was correct. The kickoff's navigate-wait-read-twice rule caught it.

A sort built on that count would have filed RingCentral with the help centres that have no links at all, and the actual barrier turned out to be different: articles that will not stay open.
