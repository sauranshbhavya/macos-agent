# Sonny contributor guidance

Read [AGENTS.md](AGENTS.md) for current engineering rules, [WORKFLOW.md](WORKFLOW.md) for build and review commands, and [README.md](README.md) for the application as it exists today. The [V2 architecture plan](sonny_v2_architecture_implementation_plan.md) gives current product direction. Read historical decisions only when they bear on the part you are changing.

The prior detailed Claude guidance is archived at [docs/archive/CLAUDE-contributor-notes-2026-09.md](docs/archive/CLAUDE-contributor-notes-2026-09.md). Its ticket ceremony, fixed review passes, full-suite-per-edit expectations, mutation plans, and branch records are no longer current instructions.

The repository still rejects generated-by-Claude attribution in commits, PR text, and tickets through its existing hooks. Keep this established team preference while using the lighter delivery workflow. Founders decide when to merge.
